## 수집 가능 여부

- **공개 목록과 문제 상세(제목·난이도·지원 언어)는 로그인 없이 읽힌다.**
- **풀이·제출에는 로그인이 필요하다** ("로그인 후 문제풀이가 가능합니다").
- 93문제 **전체 자동 수집은 미검증**. 일부 페이지 이동·필터 URL 조회가 실패했고, 원인이 동적 렌더링인지는 불명.
- `softeer.ai` 직접 조회는 이번 조사 도구로 실패했다. 원인 불명.

## 기출 여부

연습문제 **전체가 채용 기출은 아니다.** 제목에 출처가 붙어 있고, 확인된 것만도 세 갈래다.

- `[HSAT N회 정기 코딩 인증평가 기출]` — 인증평가 기출
- `[한양대 HCPC 2023]` — 대학 대회 문제
- `[21년 재직자 대회 본선]` — 사내 대회

출처 표기가 없는 문제도 많다. **문제별로 제목을 보고 판단한다.**

## 폴더 규칙

Programmers 와 같다. 파일명 `!` 접두사는 미해결, 풀면 `!` 를 떼고 `resolve:` 로 커밋한다.

```
Softeer/
├── Python/  test_runner.py · Lv1 ~ Lv5
└── Cpp/     test_runner.h · run.sh · Lv1 ~ Lv5
```

파일명은 `{식별자}_{제목}.py` 로 한다. Programmers 는 레벨 안에서 매긴 일련번호를 쓰지만,
Softeer 는 **사이트의 문제 식별자가 URL 에 그대로 있으므로** 그것을 쓰는 편이 역추적이 쉽다.
예) `Lv1/!6295_A+B.py` → https://exam.hyundai-ngv.com/practice/6295
